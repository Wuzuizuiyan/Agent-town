# 2.7 建设

（本文档含 v0.9a 的 2.7 全节。v0.10 改动：施工工期系数化、「出工刚性」措辞统一、荒废计数可见性、入库凭证过户落为子动作。v0.13 改动：2.7.7 增评审意见【二期】观察项。v0.14 改动：2.7.0 选址占地、工地=项目占地、绑定/仓储/撤筹动作衔接。v0.15 改动：审定必须带已登记效果键。）

建筑分两类，落成条件按《建筑配置表》「类别」列区分：

- 建造类：木材 + 镇币 + 工时三项凑齐。
- 改造类：按条目自定义条件（地块、工时、配方折算），支持「不同建筑不同造价」，具体见各条目。

配方折算（改造类通用规则）：木材可按《世界参数表》木材镇币折算率抵充镇币需求；材料多则可少出资金，总折算值达标即可。

属主资产（私人范式）：由单一出资人/发起人在公所发起，条件由其独自承担，建成后归其所有的资产（稻田、开垦地块即此类，通则见 2.7.6）。

公共建筑采用认筹制：任一 agent 可在公所发起项目，全镇 agent 可认筹出资（镇币/木材）、认筹出工（工时）；凑齐后开工，工时被认筹者须在该项目占地（工地）执行「出工」兑现（道路即此类）。

建筑清单不封闭：一期内置 11 种（建造类 7 + 改造类 4），均可在建筑配置表增行扩展；新建筑类型须配置类别、造价、占地宽高、允许区域、场所键、效果键，且效果键已在机制插件中登记（见 8.3/8.5），即可接入现有发起/认筹/施工流程。增行有两条路径：GM 直接增行（「来源」列=内置），或 agent 经「提案图纸」发起、附议达标并经 GM 审定后增行（「来源」列=图纸，见 2.7.7）——这是小镇自发演化的主要入口（见第 7 章）。未登记的效果不走增行，须先发版机制插件。

## 2.7.0 选址与占地（v0.14）

- 「发起项目」一律携带锚点 tile（西北角）。占地 = 锚点向东（占地宽−1）× 向南（占地高−1）的闭矩形，宽高见《建筑配置表》。道路/稻田/开垦宽高均为 1，锚点即该 tile。
- 竞选项目不占 tile、不携带锚点（见 2.12.3）。
- 校验（失败一律 E1026，与开垦非法同码、参数中区分）：
  1. 矩形完全落在《建筑配置表》允许区域内（道路允许「空地」与「住宅区」，分号分隔）；不得越出 64×64；
  2. 农田开垦仅允许待垦荒地 tile；密林开垦仅允许已解锁且未占用的密林 tile；稻田仅空地；建造类不得压在已开放农田/林地耕作格上，除非该类型允许区域就是农田/林地（田圃扩建、水井扩建按其允许区域）；
  3. 与任何已锁定占地（认筹中/施工中/已落成且未荒废）不相交；
  4. 一期无水域 tile。
- 发起成功即锁定占地；撤销项目或认筹中流拍释放；施工中流拍拆除占用（见 2.7.3）；荒废按 2.7.5 还原。
- 工地定义见 2.2.3：施工中占地 = 该项目工地。

## 2.7.1 项目状态机

```
发起 ──> 认筹中 ──凑齐──> 施工中 ──工时达标──> 落成
   │         │                │
   │         │                └─超过施工工期未达标──> 流拍
   │         └─流拍期到期──> 流拍
   └─发起人撤销（仅认筹中且零认筹时）
                    施工中不可撤销、不可退筹
```

| 状态 | 进入条件 | 允许操作 | 退出条件 |
|---|---|---|---|
| 认筹中 | 发起成功 | 认筹、撤销认筹、发起人撤销、工时委托发起（见 2.9.1） | 凑齐 / 流拍 / 撤销 |
| 施工中 | 三项凑齐 | 认筹者出工兑现、工时委托发起（见 2.9.1） | 工时达标 → 落成；超过施工工期未达标 → 流拍 |
| 落成 | 工时达标 | — | 终态；效果生效、全镇播报 |
| 流拍 | 认筹中超流拍期限未凑齐，或施工中超施工工期未达标 | — | 终态；按 2.7.3 分型清算、工地拆除 |

- 施工工期口径（v0.10 改）：施工工期 = 项目需求总工时 ×《世界参数表》施工工期系数（原固定工时对小项目过苛、对大项目过松；系数化后工期随项目规模自适应）。
- 竞选项目为特型项目（见 2.12.3），不参与流拍检查与流拍责任律。

## 2.7.2 认筹细则

- 认筹单位：镇币（≥1）、木材（≥1）、工时（≥1），可分多次追加；单次认筹即冻结对应资产进入项目托管。
- 撤销认筹：仅「认筹中」状态允许；经主动作「撤销认筹」撤回**本人在该项目的全部认筹**（镇币/木材/工时义务一并解冻返还，不可只撤一部分）。「施工中」不可撤销（E1045）。
- 发起人撤销项目：经主动作「撤销项目」；仅认筹中且全镇对该项目认筹合计为 0 时成功，保证金退还；否则 E1045。
- 凑齐判定：各项需求均 ≥《建筑配置表》需求值时，于下一 tick 结算时转入施工中；改造类镇币需求允许木材按折算率抵充后判定；超额认筹部分按提交时间逆序退还。
- 出工兑现：施工中持有该项目工时义务的 agent 在**该项目占地内**执行「出工」，每次耗时 60 分钟、兑现 1 工时（刚性：每次兑现恒为 1 工时，不受心情档位、熟练度、特质等任何乘算影响；v0.10 措辞统一）；出工前提为持有该项目工时义务（本人认筹或经工时委托受让，见 2.9.1），不在占地内返回 E1006，无义务返回 E1007。
- 认筹者中途退出或被冻结：义务不自动转移，项目流拍风险共担；被冻结的认筹者可经解冻后发起工时委托化解，或由同项目非冻结认筹者发起义务接管（见 2.9.1）；未化解时，其已兑现工时保留计入项目进度，未兑现部分导致项目停滞，直至超过施工工期未达标而流拍（见 2.7.1）。

## 2.7.3 流拍规则

- 流拍判定（日结第 4 步检查）：认筹中超过《世界参数表》项目流拍期限未凑齐，或施工中超过施工工期未达标（见 2.7.1）。
- 流拍清算分两型（两型均清除工地状态）：
  - 认筹中流拍：出资（镇币、木材）全额退还各认筹者，资金来源=公共池的镇长拨款部分退还公共资金池（见 2.12.3）；此时已兑现工时恒为 0，无工时补偿。
  - 施工中流拍：已消耗的出资（镇币、木材）不退还；已兑现工时由公共资金池按《世界参数表》流拍工时补偿单价补偿，池余额不足时以该项应付总额为分母、按日结步序依次扣减池余额等比发放，欠额不追溯补扣、记镇报「异常标记」栏（精力已消耗不恢复）。
- 流拍时仍未兑现的工时委托单据终止，托管工资解冻退还发起人（见 2.9.1）。
- 项目保证金：发起人发起项目时按《世界参数表》项目保证金缴纳并托管于项目；落成时退还发起人，流拍时没入公共资金池（与工时补偿支出池内对冲）。
- 流拍事件经老册向全镇播报（见《NPC配置表》），并写入镇志（见 5.5）。

## 2.7.4 建筑效果细则

- 住宅：每栋可绑定 agent 数见《建筑配置表》住宅条目与《动作前置表》住宅绑定容量；**办理地点=公所地理区域**（到公所办手续，不必站在住宅占地）。绑定/解绑走主动作「绑定」（见 3.1）。绑定后在**本人绑定住宅占地内**睡眠，精力恢复获得乘算加成（《动作前置表》住宅睡眠加成）；解绑即时生效，同一时间只能绑定一处。他人住宅占地不可睡眠（E1006）。未绑定者可在住宅区且场所为空的 tile 睡眠（无加成）。
- 仓库：agent 在公所经「绑定」绑定一座已落成仓库（办理地点=公所；全镇仓库容量共用《动作前置表》仓库容量上限，按本人食物单位+木材单位合计）。存入/取出须站在**任一已落成仓库占地**内，走主动作「仓储」。存入将物品换成入库凭证；取出凭证换原物（冻结中的凭证除外，见 2.6.0）。凭证可私下转让——经「私交易」动作以入库凭证为交易物品，凭证类私交易双方须同位于公所。达容量上限拒存（E1044）。
- 酒馆：站在酒馆占地内对话，心情收益翻倍（见 2.4.1）。
- 议事厅：一期落成后解锁「发起公投」主动作与 plebiscites 感知键（见 2.12.4）；发起公投仍在公所地理区域办理（见 2.12.4）；「提案」动作【二期】；周会【二期】（见 2.12.6）；v0.8 升级时已落成的议事厅立即解锁。
- 田圃扩建：全镇农田劳作产出乘算加成，多座叠加上限见《动作前置表》田圃扩建加成上限；占地仍可作为农田劳作格。
- 水井扩建：落成（BUILDING_DONE）时写入解锁 tile 状态，解锁《世界参数表》开垦解锁tile数个待垦密林 tile 供密林开垦；tile 确定性选取规则见 2.7.6；升级时已落成的水井扩建按落成口径一次性补写解锁 tile 状态（迁移）。
- 稻田：改造类自建于空地；落成后属主在稻田占地执行「劳作」产出食物（系数见《岗位产出表》）；非属主对稻田劳作返回 E1017；荒废规则见 2.7.5；属主资产通则与属主转让见 2.7.6。
- 荒地开垦：改造类私人范式；建于农田区域待垦荒地 tile，1 项目=1 tile，无前置；落成后该 tile 转为开放农田 tile 并归发起人属主资产（见 2.7.6）；条目见《建筑配置表》。
- 密林开垦：改造类私人范式；建于林地区域待垦密林 tile，1 项目=1 tile；仅可在水井扩建解锁的 tile 上发起（未解锁返回 E1026）；副产物（木材）按累计结算口径发放：项目累计兑现工时 ×《世界参数表》开垦木材副产物率，按累计值向下取整，于每次出工兑现时增量发放（口径见 2.7.6）；落成后该 tile 转为开放林地 tile 并归发起人属主资产（见 2.7.6）；条目见《建筑配置表》。
- 道路：改造类公共建筑；按 tile 落成于空地或住宅区未占用格，建成后提供移动耗时折减（见 2.2.2）；不荒废；道路占地可进入、可与 agent 重叠。
- 公告栏：落成后，张贴须站在公告栏占地内；`bulletin_board` 感知键在公所地理区域返回（见 2.2.3）。

## 2.7.5 荒废机制（改造类）

- 仅配置了荒废规则的改造类建筑参与检查（当前为稻田与开垦地块；开垦地块同用《世界参数表》稻田荒废阈值）。
- 日结时检查：连续无劳作记录达《世界参数表》稻田荒废阈值日 → 荒废，还原为原 tile 类型（稻田还原为空地、荒地开垦还原为荒地、密林开垦还原为密林），属主收到收件箱通知；任一日的劳作记录重置计数。处于活跃属主转让单据锁定中的资产跳过荒废检查（交割或单据取消后恢复检查，见 2.7.6）。
- 荒废不退还任何已投入成本（工时/材料）；属主可在原址重新发起建造。
- 属主转让不重置荒废计数，计数随过户继承（见 2.7.6）。
- 荒废计数可见性（v0.10 新增）：属主经感知 self.assets 键查看本人资产当前荒废计数（见 3.2）；属主转让单据与退出拍卖挂单均附当前荒废计数字段，受让方/竞拍方确认时可见（防信息不对称柠檬市场）。

## 2.7.6 属主资产通则

- 属主资产定义：持有持续所有权的改造类资产，当前为稻田与开垦地块（荒地开垦/密林开垦落成 tile）；每项属主资产有唯一属主。
- 仅属主可在其上劳作，非属主返回 E1017；劳作产出系数见《岗位产出表》。
- 荒废：荒废规则随《建筑配置表》各条目配置（见 2.7.5）。
- 属主转让：独立主动作（见 3.1），复用私交易「发起 → 锁定 → 确认 → 交割」管线（参照 2.6.2），参数：受让方、资产 ID、对价（≥0，对价 0 即赠予）。
  - 前置：发起人为资产属主；资产未荒废且不处于托管/抵押中；受让方为同区域定居者且关系值不低于拒绝门槛（见 2.8.1）；受让方按可用余额足额锁定 对价 + 《动作前置表》属主转让过户费（见 2.6.0，不足返回 E1023）。违规返回 E1025。
  - 流程：发起（生成转让单据，单据附当前荒废计数，见 2.7.5；受让方锁定对价与过户费，属主锁定资产，见 2.6.0）→ 受让方在《动作前置表》转让确认时限内经「转让确认」响应子动作确认（见 3.1.3），确认时重校验标的资产存在且未荒废，校验失败返回 E1025 并自动取消单据、解锁双方资产 → 交割：资产属主过户至受让方、对价划转属主、过户费入公共资金池；超时自动取消并解锁双方资产。
  - 确认期间发起方不可撤回；荒废计数随过户继承；转让单据幂等键 = 单据 ID + 操作类型（见 3.1.1）。属主转让不适用改价机制（见 2.6.2），对价以发起单据为准。回滚口径：本机制无独立停用开关，停用口径=随 v0.7a 批次整体回滚（见《动作前置表》属主转让过户费备注）。
- 开垦项目专项：开垦项目以私人范式发起（「发起项目」参数含目标 tile = 锚点）；目标 tile 确定性选取（agent 提交的 tile 须等于规则选出的合法格之一，或提交后由服务端按本规则校验存在）：在对应区域已解锁且未被占用的待垦 tile 中，取与已开放区四邻接相邻者，按坐标 **(-y, x)** 序。发起即校验，违规返回 E1026；一个开垦项目=1 tile，发起人即属主，二次分配走属主转让；落成即属主资产；密林开垦副产物（木材）= 项目累计兑现工时 ×《世界参数表》开垦木材副产物率，按累计值向下取整，于每次出工兑现时增量发放；水井扩建 BUILDING_DONE 时按同一排序从剩余密林中取《世界参数表》开垦解锁tile数格写入解锁状态（不足则全数解锁）。
- 退出衔接：属主资产的属主退出时，资产以属主凭证入 3.3.4 公示拍卖（挂单附荒废计数，见 2.7.5）；退出触发的属主转让单据一律撤销、双方锁定解锁返还，该终止不视为违约、不收过户费。

## 2.7.7 图纸提案

- 「提案图纸」为主动作（见 3.1）：位于公所；每次按《动作前置表》图纸提案费缴费入公共资金池，图纸费一律不退（作废/驳回同）；每人每日提案数 ≤《动作前置表》每人日图纸提案上限。
- 参数与校验：建筑名称（长度 1–《动作前置表》图纸名称长度上限字，不与现有建筑及在途图纸重名）、类别（建造类/改造类）、造价三项（木材/镇币/工时，各受《动作前置表》图纸造价_系列上限钳制）、效果说明（≤《动作前置表》图纸效果说明长度上限字）；全镇在途图纸（提案中+待审定）总数 ≤《世界参数表》在途图纸上限。违规返回 E1031。
- 图纸状态机：

```
提案中 ──附议数达门槛──> 待审定 ──GM 通过──> 已启用
   │                        ├─GM 驳回──> 已驳回
   │                        └─超待审定时限未审定──> 已驳回
   └─图纸有效期届满未达标──> 已作废
```

| 状态 | 进入条件 | 允许操作 | 退出条件 |
|---|---|---|---|
| 提案中 | 提案成功 | 附议图纸（见 3.1.3） | 附议达门槛 → 待审定；有效期届满未达标 → 已作废 |
| 待审定 | 附议达门槛 | GM 图纸审核（见 5.4）；【二期】挂评审意见卡（不改变出口） | GM 通过 → 已启用；GM 驳回 → 已驳回；超待审定时限 → 已驳回（图纸费不退，经老册播报） |

- 有效期口径：图纸有效期同按镇内日粒度计（发起当日计第 1 日，于届满日的次日日结第 7 步子步 3「到期清理」判定作废，见 2.1.2/2.12.4）；届满判定时已转入「待审定」的图纸不适用作废。
- GM 审定口径：通过时按提案设计卡在建筑配置表增行，工期、效果值、荒废规则、**占地宽高、允许区域、场所键、效果键**由 GM 审定，「来源」列=图纸，次日日结热更新生效（见 6.1）；缺占地字段或效果键未登记视为非法行保留旧表并记 SETTLE_ERROR（见 8.3）。「已启用」以增行通过次日配置加载校验为准——未通过校验则回退「待审定」并经老册播报异常（记 SETTLE_ERROR），GM 修正后于再次日生效，「图纸启用累计数」以加载成功时点计数；GM 审核通过时须复核不与在途图纸及当日已增行未生效的名称重名，冲突则驳回。效果键可与已有建筑复用（场所键仍须唯一）；一期效果值不解析为公式，插件读数走既有配置行。
- 评审意见【二期】（v0.13 观察项；一期不生成、不增字段）：图纸由「提案中」转入「待审定」时，世界生成一张评审意见卡并挂到该图纸。状态机、待审定时限、超时驳回与 GM 通过/驳回出口均不变——评语不是审定。
  - 适配信号：读取日结第 8 步既有演化指标与镇报公开栏，生成确定性清单（仓库/议事厅是否已落成、道路连通对数、图纸启用累计数、全镇人口、公共资金池余额、时间利用分布中劳作与出工占比）。清单只陈述事实与建议语气（如「仓库未落成」「枯水季储备不足」「与已有建筑效果说明重复」），**不得据此自动驳回或自动通过**（无硬性阶段门，见 7.1/7.3）。
  - 评语文案：LLM 按老匠性格三词与职能知识将清单译为评语；硬边界同 3.4.2——仅文本，不改造价三项、工期、效果值或审定结果。服务不可用回退模板评语，记 SYSTEM 降级。
  - 可见性：评语与适配信号写入公所区域 blueprints 该条（落地时追加字段，见 3.2）；镇报「当日要事」在图纸进入待审定时可附评语摘要。监测周报不对 agent 广播（见 2.12.6/5.4）。
  - 待审定图纸可进入周会题池（见 2.12.6）；周会排序不替代 GM 图纸审核（不可下放，见 2.12.3）。
- 「附议图纸」为响应子动作（见 3.1.3）：一人一票不可撤、发起人不可自附、附议方须为定居者（NPC 不附议，见 3.4）、无区域限制（与投票类子动作口径一致）；违规返回 E1032。
- 播报与感知：附议达标/启用/驳回/作废经老册向全镇播报（见《NPC配置表》），记 BLUEPRINT 事件（见 5.1.1）；公所区域感知 blueprints 键返回在途图纸列表（见 3.2）；发起人冻结或退出不影响在途流转（照常附议与审定，发起人以归档 agent_id 标识，见 3.3.4）。
