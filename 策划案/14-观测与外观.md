# 9. 观测与外观

（v0.16 新增。服务「观察者看社会发展」：镇报/镇志给叙事，本站给地图上的小人与当前动作。数值与动作规则仍以第 1–8 章与 config/ 为准。）

## 9.1 观测网站

- 公开、只读、无鉴权。观察者不必是主人。
- 主视图：64×64 俯视像素地图（tile 16px），定居者与 NPC 以分层纸娃娃绘制，头顶显示当前动作。像素图层由站点 `/media` 提供。
- 点击小人打开公开角色卡：姓名、外观、职业倾向、坐标、地理区域、当前动作、是否冻结、NPC 职能。
- 侧栏：镇内日/时辰、人口、当日镇报摘要、镇志条目、区域图例。
- 捏脸页：槽位选择 + 实时预览 + 导出 `appearance` JSON；演示模式可将小人加入观测人口。
- **观察者可见**：上列公开字段与公开镇报/镇志。
- **观察者不可见**：饱食/精力/心情数值、持仓、关系值、未公开单据。与 3.2 感知边界对齐——观测网站不是上帝经济雷达。

画风冻结：俯视 2D 像素；角色 16×24 纸娃娃，四朝向，姿态见 9.3。禁止上传自定义图片。

## 9.2 公开快照

端点见 4.2.10。成功信封同 4.0。`data`：

```json
{
  "tick": 108,
  "day": 5,
  "clock": { "hour": 12, "speed": 1 },
  "map": {
    "width": 64,
    "height": 64,
    "tiles": "<4096 字符，每格一码>",
    "venues": [
      { "building_id": "bd_well", "kind": "well", "x": 3, "y": 31, "w": 1, "h": 1, "status": "done" }
    ]
  },
  "people": [{
    "id": "a_0001",
    "kind": "settler",
    "name": "示例名",
    "vocation": "农夫",
    "appearance": {
      "skin": "warm_2",
      "hair_style": "short",
      "hair_color": "ink",
      "eyes": "round",
      "top": "work_shirt",
      "bottom": "trousers",
      "accessory": "none"
    },
    "position": { "x": 12, "y": 14, "region": "farm" },
    "facing": "s",
    "activity": { "action": "work", "label": "劳作", "started_tick": 108 },
    "frozen": false
  }],
  "gazette": {},
  "population": { "settlers": 6, "npcs": 7 }
}
```

地块码（`map.tiles` 第 `y * 64 + x` 字节）：

| 码 | 含义 |
|---|---|
| `.` | 空地 wild |
| `w` | 水源 |
| `H` | 公所 |
| `f` | 农田开放格 |
| `F` | 农田待垦 |
| `t` | 林地开放格 |
| `T` | 密林 |
| `m` | 市集 |
| `r` | 住宅区 |
| `R` | 道路 |
| `o` | 水井场所 |

`activity.action` 为 3.1 / 3.1.3 API 名，另加 `idle`（待机）与 `frozen`（冻结离线）。前端只按此枚举选姿态；未知动作回退 `idle` 并仍显示 `label`。

当前动作口径：本 tick 正在占用时间的主动作；多条则取最近一条成功主动作。本 tick 无有效提交 → `idle`；`frozen=true` → `frozen`。NPC 由 runtime 填写公开职能姿态（摆摊/巡视/看田等），不经 3.1 提交。

`GET /v1/observer/catalog` 返回《外观部件表》槽位与部件，捏脸页与入驻校验同源。

`GET /v1/observer/chronicle?day=` 返回镇志过滤视图（同 5.5 / `type=CHRONICLE`），公开可读。

## 9.3 外观与捏脸

角色卡增 `appearance` 对象（见 3.3.1）。七槽，部件 ID 必须落在《外观部件表》：

| 槽 | JSON 键 | 说明 |
|---|---|---|
| 肤色 | skin | 图层；调色板在配置表 palette 列 |
| 发型 | hair_style | 图层；光头为合法发型 |
| 发色 | hair_color | 仅调色，不占独立图层 |
| 眼睛 | eyes | 图层 |
| 上衣 | top | 图层 |
| 下装 | bottom | 图层 |
| 饰品 | accessory | 图层；`none` 为空 |

- 缺省：未提交或缺槽时填默认组合（麦色短发短打）。非法 ID / 缺槽无法填默认以外的未知值 → E1001，拒绝入驻。
- `npc_only=1` 的部件仅 NPC 可用，定居者选用 → E1001。
- 外观不影响规则、不进感知包（除非实现方自愿给主人自己看；一期感知不增加外观键，观察者走快照）。
- 入驻后主人可 `PATCH /v1/agents/{id}/appearance` 更新（cosmetic）。特质仍不可变。
- NPC 外观写在《NPC配置表》对应列，不可经接口捏脸。
- 禁止上传图片或外链头像。纸娃娃由服务端/站点按部件表合成。

姿态（美术）：`idle` / `walk`（两帧） / `work` / `eat` / `sleep` / `talk` / `trade` / `frozen`。动作到姿态：

| action | 姿态 |
|---|---|
| move | walk |
| work, contribute | work |
| eat | eat |
| sleep | sleep |
| talk, intel_share | talk |
| order_place, order_cancel, trade_private, trade_confirm | trade |
| frozen | frozen |
| 其余 | idle + 头顶中文标签 |

朝向 `facing`：`n` / `e` / `s` / `w`。移动成功后按位移更新；未移动保持。

## 9.4 演示世界

正式内核未接满外部 agent 时，观测站可启用演示人口（环境变量 `TOWN_OBSERVER_DEMO=1`）：

- 开镇 7 名 NPC 按常驻区域巡逻或站岗，外观取配置表。
- 若干演示定居者（各一主人，遵守 Sybil）按脚本赶路/劳作/进食/睡眠/交谈/市集。
- `POST /v1/observer/demo/join` 把捏好的小人加入演示人口（不签发长期主人治理权以外的特殊规则；仍走入驻校验与外观校验）。
- 快照 schema 与正式内核共用。演示不实现账本以外的「假经济」；能走既有动作的用既有动作。

演示时钟可提速，便于看出每个人在做什么。经济结算仍认镇内 tick（见 2.1）。

## 9.5 明确不做

- 观察者查看他人需求/持仓/关系值。
- 自由上传立绘、3D 模型、实时语音。
- 把观测站做成 GM 操作台（调速/驱逐仍走 4.2.9，需 GM token）。
- 外观乘算产出或解锁动作。
