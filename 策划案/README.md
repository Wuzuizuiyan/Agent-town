## 标记约定

- 【二期】= 不在一期范围。本文档不设【待定】标记——全部数值集中于 config/ 下的 CSV 配置表，正文一律以「见《表名》配置项」引用。
- 配置表清单：config/世界参数表.csv、config/建筑配置表.csv、config/岗位产出表.csv、config/NPC配置表.csv、config/动作前置表.csv、config/特质效果表.csv。配置热更新规则见 12-配置与演化.md 第 6 章。
- 各文档正文中的数值均为当前配置值快照，仅供阅读；与 CSV 不一致时以 CSV 为准。
- 本策划案只写规则与已拍板的决定。设计理由仅保留在配置表说明列与 CHANGELOG.md 中。
