## 0. 一句话结论

**规则层已经够「砍一刀就能开工」，还不能按一期全文直接开写。**

真正挡住「开始做 MVP」的不是 v0.13 那些【二期】观察项，也不是数值还没跑镇——而是三件事叠在一起：

1. **MVP 范围从未冻结**：文档里的「一期」是完整 v1，不是最小可玩切片。
2. **约 10 个会卡住编码的规格洞**：建筑落在哪、工地在哪、住宅/仓库怎么绑、缺两行配置、NPC 吃不吃玩家食物。
3. **运行时为零、接入契约只写到端点清单**：仓库里没有世界服务器，第 4 章还不够给朋友对接。

若把「开始制作 MVP」理解成「能写 tick 循环、能让 2–5 个 agent 活过几天」——**再补一轮小规格冻结即可开工，不是还差半本策划案。**
若把「MVP」理解成「一期 22 个主动作 + 契约/治理/图纸/悬赏/NPC 对话全部可玩」——那是完整一期，工作量大约是最小切片的三到四倍机制面，不建议当第一枪。

## 2. 已经够用、开工不必再争论的

下列在正文与 CSV 里已经拍板，写核心循环时可以直接当规格用：

- 世界身份：荒地拓居点；定居者（外部 agent）与老居民（内置 NPC）同规则、不同权限（见 `01-世界总览.md`、`09-agent行为集与生命周期.md` 3.4）。
- 时间：1 tick = 镇内 1 小时；每 tick 60 分钟时间预算；日结九步顺序固定（见 `02-时间与空间.md`）。
- 空间：64×64 与六块功能区坐标已给出（见 2.2.1）。
- 生存：饱食 / 精力 / 心情来源全表、三档产出、特质乘算位（见 `03-资源需求与工作.md`）。
- 经济：食物 / 木材 / 镇币；市集撮合伪代码；阿市只卖不买 + 动态锚价；发行回收口径表（见 `03`、`04`）。
- 加压数值已落 CSV，且经 30 日粗模拟：全职能活、躺平挨饿、枯水季必须储备、公共池 30 日不破零（见 `校验报告.md`）。
- 接入骨架：拉/推双模式、幂等键 `tick + token + 动作名 + seq`、错误码 E1001–E1043 已登记（见 `10-接入接口协议.md`、3.1.2）。
- 红线已写死：NPC 经济特权永久禁区；LLM 只出文本、不改状态（见 3.4、7.3）。

一期边界里已经明确不做、**MVP 更不应做**的：石料、阿市双向做市、信用贷、资源枯竭、公投自动改规则、NPC 态度挂钩仓储优惠、v0.13 周会与图纸评语。完整清单见 `12-配置与演化.md` 7.3。

## 3. 开工前必须补的规格洞（P0）

这些不是「可以边写边想」的味道问题。任一未决，核心循环都会在实现中卡住或各写各的。

建议用一次短会拍板，写成「MVP 冻结附录」（可直接补进各章，不必另起版本号哲学）。大约 **10 个决策**，不是 10 章新文。

### 3.1 建筑落在哪、工地在哪（空间模型最大洞）

2.2.1 的区域是静态划分。建造类建筑（住宅、仓库、酒馆、公告栏、议事厅等）**没有选址规则、没有占地 tile 数、落成后不定义新区域**。

但规则又依赖「区域」：

- 「出工」前置是「位于工地」（3.1），工地 tile / 区域未定义。
- 「张贴公告」要求位于「公告栏区域」（E1024）；`bulletin_board` 仅该区域返回。
- 酒馆「区域内」对话心情 ×2；老库常驻「仓库」、阿禾常驻「酒馆」——这些建筑在 64×64 上没有位置。
- 道路是按 tile 的改造类，但「发起项目」只写开垦类携带目标 tile，道路同样需要目标 tile，未列入参数。
- 「建筑 tile 不可通行」（2.2）——若建筑占地未定义，不可通行也无法执行。

不补这一条，**建设系统无法编码**。MVP 若砍掉建设，本条可降为 P1；只要第一枪包含认筹/出工/仓库，就必须先拍板。

可选拍板（实现成本由低到高）：

- A. **MVP 简化**：公共建筑落成只改「全镇解锁标记」，不占新 tile；出工在公所执行；酒馆/公告栏效果挂在公所或市集的子区。道路与开垦仍按 tile。
- B. **发起项目一律带目标 tile + 占地表**：每类建筑在《建筑配置表》加「占地」列；工地 = 目标占地；落成后这些 tile 标为该建筑并不可通行（或可进入的室内 tile 另标）。

### 3.2 动作表缺四类高频操作

3.1 列了 22 个主动作，但正文多处使用了表中不存在的操作：

| 正文已写的行为 | 出现位置 | 动作表 |
|---|---|---|
| 绑定 / 解绑住宅 | 2.7.4、E1016、睡眠前置 | 无 |
| 绑定仓库、存入、取出（换入库凭证） | 2.7.4、2.3.1 损耗、2.10 抵押 | 无 |
| 撤销认筹、发起人撤销项目 | 2.7.1 / 2.7.2 | 无（认筹动作是否兼作撤筹未写） |
| 道路 / 住宅等建造类的目标位置 | 2.7、3.1「发起项目」 | 仅开垦携带目标 tile |

另外：`2.7.4` 写住宅「绑定人数与办理地点见《建筑配置表》住宅条目」，CSV 只有「绑定 4 人；睡眠 ×1.3」，**办理地点未配**。

不补存取，仓库与 15% 食物损耗、借贷抵押全部空转。不补绑定，住宅加成与 E1016 无法触发。

### 3.3 配置表缺行（脚本目前报不出）

正文强引用、CSV 没有对应参数名：

| 引用 | 位置 | 影响 |
|---|---|---|
| 《世界参数表》开垦解锁tile数 | `05-建设.md` 2.7.4 / 2.7.6，《建筑配置表》水井扩建说明 | 水井扩建落成无法执行 |
| 《世界参数表》开垦木材副产物率 | 同上，密林开垦 | 出工副产物无法结算 |

`sim/校验脚本.py` 用「前缀收缩 + 仅强动词（见/按/超/…）」匹配，上面两处常被裁成散文或不当强引用，故历史报告「0 缺失」不可当作这两行已配。`《世界参数表》周会系列` 缺行是 v0.13 故意的【二期】，MVP 可忽略。

农田 / 林地「一期开放 40 tile」（1.1、2.2.1）也没有选取算法。区域 24×16 = 384 tile，哪 40 格开镇可用，必须定（建议：与已开放区相邻、按坐标序，与开垦选取同构）。

### 3.4 NPC 吃不吃玩家经济里的食物

3.4：NPC「进食、睡眠由 runtime 按需求系统自动安排」。未写食物来源。

开镇常驻 7 名（v0.12；`01-世界总览.md` 仍写「初始 4 名」，见 §3.6）。若按每日进食 4.32 计，仅常驻 NPC 就要约 30 单位食物 / 日，接近阿市日供 60 的一半。`sim/经济模拟.py` **没有把 NPC 消费算进市场**。若实现时让 NPC 去市集买粮，加压经济会被静默改写。

建议拍板：**NPC 需求只走内部结算，不从市集/公共池扣玩家食物；阿市卖单的货源是系统供给，不是 NPC 个人库存。** 与「NPC 经济特权禁区 / 阿市零裁量」一致。

### 3.5 移动到底校验什么

2.2.2：耗时 = 曼哈顿距离 × 每 tile 耗时；「途经是否绕行由 agent 自行分多 tick 规划，服务端只校验单次位移」；目标不可通行则拒（E1003）。未写：路径被建筑挡住时，是按直线曼哈顿收费并「瞬移」，还是拒单？

道路加成：「起点与终点均为道路 tile 则全程按道路耗时」——中间穿过非道路时仍享受道路价，可被利用。

MVP 建议：单次位移按曼哈顿收费，不检查中间格子（与原文「不校验途经」一致）；道路加成改为「起点、终点**且**曼哈顿路径上每一格都是道路」才折减。若采用 3.1-A（公共建筑不占 tile），挡路问题会轻很多。

### 3.6 文档漂移（小，但会误导实现）

- `01-世界总览.md`：「初始 4 名」NPC。v0.12 起开镇常驻 7（阿市/老册/老卫/老镇/老禾/老柴/老匠）。以 `NPC配置表` 与 3.4 为准。
- `12-配置与演化.md` 6.2 仍写 NPC 名单「阿市、老册、老卫、老镇」。
- 感知示例 JSON 中英混用（`tick` / `饱食` / `入驻日`）。接入方会按示例抄。MVP 应冻结一份字段名（建议：对外 JSON 一律英文蛇形，中文只出现在镇报文案）。
- `6.1` 写「正文数值为 CSV 快照」——多数章节已改成「见《表名》」，仍散落少量快照数，以 CSV 为准即可，不必开工前清完。

### 3.7 开发时钟（产品决策，不做会无法测）

正文：1 tick = 现实 1 小时，与北京时间对齐；GM 调速最高 4×（15 分钟 / tick）。按此节奏，测「一天日结」要 6–24 小时现实时间。

MVP 必须另有一档 **模拟时钟**（例如 1 tick = 1–10 秒，或「GM 推进 N 个 tick」），并规定：调速/暂停期间冻结、webhook 时限、委托有效期仍按**镇内时间**计。这不改经济规则，只改现实墙钟映射。`2.1` 现有 0.5×/2×/4×/暂停不够开发与试玩。

### 3.8 数值精度与同 tile 叠放

- 产出「向下取整为整数单位」，感知示例镇币为 `13.2`。须定：镇币用小数（建议两位）还是最小面额；食物/木材是否允许小数（损耗 15% 向下取整暗示食物是整数）。
- 多 agent 能否同 tile：未写。投放「住宅区中心 tile」若所有新人同一格，必须允许重叠，或改为按坐标序找空位。

### 3.9 主人是谁

4.2：「主人凭证」与 agent token 分离，但没有主人注册端点、凭证格式、如何把 GitHub/邮箱映射到「每主人 ≤ 1 个活跃定居者」。Sybil 限制（E1039）依赖这个身份。MVP 可极简：邀请码表 + 一个 API key = 一个主人。

## 4. 建议的 MVP 切片（第一枪）

目标：**2–5 个外部 agent + 阿市/老册（系统，不必 LLM）能在同一张图上活几天**——能饿、能睡、能干活、能买卖、能看见日结，主人能读日志。

### 4.1 第一枪要做

| 模块 | 做到哪 | 可砍的细节 |
|---|---|---|
| tick 循环 | 五步管线 + 时间预算 + 日结里与生存/生产/市集相关的步 | 悬赏兑付、竞选计票、NPC 态度快照可空转或不开 |
| 地图与移动 | 64×64、区域感知隔离、曼哈顿移动 | 道路可后做；建设占格若选 3.1-A 则更简单 |
| 需求 | 饱食/精力/心情衰减与进食睡眠 | 特质可只实现「无特质」；心情三档可留 |
| 工作 | 农田/林地劳作、公所杂役、空地采集；日结产出与劳动铸币、以工代赈 | 熟练度可先做累计工时但不分档 |
| 市集 | 挂单/撤单/撮合/税率；阿市日结补卖单 | 委托单可只做「条件进食」或整类后置 |
| 接入 | 注册、感知、提交行动、拉模式；简单主人 key | 推模式 webhook、重签、读日志可第二枪 |
| 日志 | AGENT_ACTION / TRADE_MATCH / DAY_SETTLE / SETTLE_ERROR | 镇报五栏可先纯文本日小结 |
| 生命周期 | 入驻投放、待机、冻结（连续无提交） | 退出拍卖可第二枪 |

### 4.2 第一枪明确不做（一期里已经写细、但会拖死切片）

- 雇佣 / 工时委托 / 借贷 / 担保 / 契约自定义条款
- 属主资产、开垦、荒废、属主转让（依赖 3.1–3.3，且不是「活下来」刚需）
- 图纸提案、公投、竞选、悬赏、执法全套（镇长可固定为老镇、不开放竞选）
- 情报分享、声望等级特权
- NPC LLM 对话、态度、竞选投票、老册闲谈、建筑激活 NPC
- v0.13 周会 / 评审意见 / 监测周报
- GM 图形工具（改 CSV + 一个调速/暂停接口即可）

仓库在加压基调下是「早期刚需」（15% 日损耗）。若第一枪不做仓库：可临时把损耗关掉或降到 0，并在镇报写明「仓储未开放」；**不要**在无存取动作时仍按 15% 扣，否则无法囤粮、季节故事不成立。更干净的做法：第一枪就做「公所存取」三动作（绑仓库 / 存 / 取），建筑本身用 3.1-A 的全镇解锁标记（开镇即有一座系统仓库，或第一座仓库用 GM 放置）。

### 4.3 相对一期的体量

粗算机制面（不是工时估计）：

- 一期已写细的系统块 ≈ 建设、契约、治理、社交情报、季节事件、NPC 生态、悬赏、接入、GM/镇志。
- 第一枪大约覆盖其中 **时间 + 空间 + 生存 + 岗位 + 市集 + 最小接入**，约一期机制面的 **1/4 到 1/3**。
- 余下一期内容是「开镇稳定后再加」，不是开工前置。

## 5. 工程侧还缺什么（不写也能开工，但不给朋友对接）

第 4 章现在是**端点清单 + 散文字段**，距离可实现的 API 合同还差：

- 每个主动作 / 子动作的请求 JSON schema（参数名、类型、必填）。
- 统一错误包：`{ "code": "E1008", "message": "...", "tick": N }`；HTTP 状态码约定。
- 鉴权：`Authorization` 怎么带 token；webhook 如何验真（签名或共享密钥）。
- 感知包正式 JSON Schema（现在 3.2 标注了 schema，实际是示例对象）。
- GM 操作是否走 HTTP（5.4 只有功能表）。
- LLM：模型、prompt 槽位、超时、降级模板正文——**第一枪不做对话即可整段推迟。**

技术选型（语言、数据库、tick 调度、单进程 vs 队列）策划案有意未写，由实现方定。对这个项目体量，**单进程权威服务器 + 日结事务 + CSV 热加载**足够支撑第一枪；不要在开工前先做分布式。

`sim/` 的定位保持：改参回归，不是 runtime。经济模拟把配置写死在 Python 常量里，与 CSV 会再漂移——这是已知债，不挡 MVP；若开写，runtime 应只读 CSV。

## 6. 建议的开工顺序

1. **冻结 MVP 切片**（本文 §4）——写进 README 或本章文末「已拍板」段，避免实现时把一期全文当待办。
2. **一次补完 §3 的 P0**（10 个决策里，与切片相关的必须当场定；开垦两行配置若切片不含开垦可仍缺）。
3. **写世界服务器垂直切片**：tick 循环 → 入驻/感知/行动 → 劳作进食睡眠 → 市集 + 阿市 → 日结损耗与产出。
4. **用 1–2 个脚本 agent 打通 3 个镇内日**（模拟时钟），再请朋友接真 agent。
