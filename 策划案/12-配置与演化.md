# 6. 配置管理 · 7. 小镇演化

（本文档含 v0.9a 的第 6、7 章。v0.10–v0.13 兼容说明见 7.4–7.8。v0.14 改动：建筑占地加载校验、7.9 第一枪排期、7.10 可开发冻结兼容说明。）

## 6. 配置管理

### 6.1 热更新规则

- 配置文件为 config/ 下 6 张 CSV：世界参数表、建筑配置表、岗位产出表、NPC配置表、动作前置表、特质效果表。
- 加载时点：每日 00:00 日结第 1 步；修改 CSV 后最迟次日日结生效，tick 中途不变。
- 合法性校验：加载时校验取值范围与字段完整性；《建筑配置表》须含占地宽、占地高、允许区域、场所键，缺列或非正整数占地视为非法行；非法值保留旧值继续运行，异常写入镇报「异常标记」栏（SETTLE_ERROR）。
- 变更审计：每次生效的配置变更（变更项、旧值、新值）写入系统事件日志（CONFIG_RELOAD）。
- 本文档正文中出现的数值均为当前配置值的快照，仅供阅读；两者不一致时以 CSV 为准。
- 新配置资产热更兜底：特质效果表整表缺失或新增参数行缺失/非法时，按保守缺省回落并记 SETTLE_ERROR：池联动类参数按 0 处理（拨款限额退化为《世界参数表》镇长拨款日限额固定值），特质效果表按空表处理（特质字段校验不通过，拒绝带特质的入驻）；特质效果表行只可调值，不可删除或改名，删除/改名视为非法值保留旧行。
- 删除配置项的口径（v0.10 补明）：v0.10 删除了 AP 系列配置项（基础行动点、精力充沛AP阈值/加成、各动作 AP消耗、劳作/出工每tick次数上限、每tick移动上限、道路移动加成）——存量 CSV 中残留这些行时视为未知行忽略并记 CONFIG_RELOAD 提示，不视为非法值。

## 7. 小镇演化

### 7.1 演化主路径：自发建设

- 小镇变好的主载体是 agent 的自发建设行为：自发开稻田、自发认筹修路、自发筹建仓库/酒馆等公共设施、自发提案新建筑图纸（见 2.7.7）。
- 世界不提供预设的「升级路线」或里程碑解锁；演化方向完全由 agent 集体行为决定。
- 演化入口保持开放：《建筑配置表》可增行新建筑类型（配置类别、造价与占地即可接入现有流程），无需改代码改规则；v0.8 起 agent 可经「提案图纸」发起增行（附议达标 + GM 审定，见 2.7.7），增行入口从 GM 专属扩展为全镇共创；石料等新资源【二期】接入后可支撑更复杂的改造类配方。

### 7.2 演化的自稳定机制

| 机制 | 作用 |
|---|---|
| 荒废机制（2.7.5） | 无人维护的设施退场，防止僵尸建筑占位；「变好」需要持续投入维持 |
| 配方折算（2.7） | 材料多可少出钱，不同禀赋的 agent 都能参与建设 |
| 认筹制（2.7.2） | 单个 agent 力所不及的工程可全镇合力；协作网络随之生长 |
| 道路耗时折减（2.2.2） | 修路有直接回报（通行省时），形成「建设→受益→再建设」的正循环 |
| 演化指标（5.3） | 主人可观察演化进度；镇报每日公布 |

### 7.4 v0.10 兼容说明（接入方必读）

v0.10 为**破坏性升级**。不新增端点，但行动提交契约与感知字段有变更：

- 【破坏】时间预算制替代 AP 系统（见 3.1.0）：感知 ap_remaining 字段移除，新增 time_remaining（分钟）；「每 tick 1 主动作/AP 消耗」心智模型整体作废——动作按耗时计费，同名动作同 tick 可重复。
- 【破坏】行动提交请求增必填字段 seq（客户端序号，见 4.2.3）；幂等键变为 tick + token + 动作名 + seq。旧客户端不带 seq 的提交按 E1001 拒绝。

- 【追加】错误码 E1039（主人限额/再入驻冷却）、E1040（情报单据非法）。
- 【追加】响应子动作 10 → 12：新增「担保确认」「情报确认」。
- 【追加】主动作参数：雇佣增「总工时」必填参数（见 2.9.2）；借贷可携带 contract_options.guarantor。
- 【追加】事件类型：INTEL_SHARE（见 5.1.1）。
- 【追加】感知字段：self.assets（属主资产含荒废计数）、self.relations 条目增 累计交互次数/最近交互tick、contracts 条目增 约定总工时/已交付工时。

### 7.9 建议的第一枪切片（v0.14，非规范削减一期）

一期规则在 v0.14 已可按全文实现。若人力只够先开镇，建议实现顺序（**不是**把未做部分标成二期——未做只是工程排期）：

1. tick 五步管线、时间预算、墙钟/`tick现实秒数`、GM 调速与推进
2. 64×64、地理区域、move、同格重叠、入驻投放
3. 需求、eat/sleep/work（农田/林地/杂役/采集）、日结产出与劳动铸币、以工代赈
4. 市集 order_place/cancel 撮合、阿市系统卖单、税率
5. 拉模式：owners/register、agents/register、perception、actions
6. 日志 AGENT_ACTION / TRADE_MATCH / DAY_SETTLE
7. 随后：warehouse 存取（若暂不做，须把未入库食物日损耗热更为 0，避免无法囤粮）、道路、standing_order 的 auto_eat、冻结
8. 再后：project_create 占地与认筹出工、bind 住宅
9. 契约、治理、悬赏、NPC LLM：有跑镇数据后再加

第一枪可把 NPC 做成常驻坐标上的系统角色（阿市补单 + 老册日结播报），对话返回模板，不接 LLM。

### 7.10 v0.14 兼容说明（接入方必读）

v0.14 为**可开发冻结**，对尚未存在的客户端为破坏性字段冻结（本仓库此前无运行时客户端）：
