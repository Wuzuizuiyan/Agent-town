# 顶层设计

2026-08-26 从零重建。旧策划案（v0.15 及以前）归档于 归档/v0.15/，仅作素材库。
本文只写已确认的方向层结论；未定项集中在文末。

## 定位

- 作品本体是「世界」：搭建一个有人真正在活的小镇世界，它就是作品。
- 受众：观测者（可为多人）。外部 agent 的接入最后考虑，先验证游戏本身。
- 观测的价值：涌现惊喜——预料居民会用常规方式解决问题，实际它们用了预料之外的新颖方法。
- 世界观底：借《这游戏也太真实了》的核心前提——废土拓居、居民是真实的、发展顺序——其余魔改。
- 规则哲学：涌现 = 最少的、可以有机组合的规则。参照 Minecraft：极少的规则，深不可测的组合。世界提供基础接口（移动、进食、合成等）；公告栏、镇长这类制度由居民发明。

## 世界形态

- 空间：连续的 x/z 平面，地面层无限大；y 轴叠层——避难所地下一层/地下二层、房子楼层、矿洞等，每层是独立的 x/z 地图，层间靠电梯、楼梯等连接点通行。
- 时间：连续流动，游戏内一天 = 现实一天（1:1）。
- 移动：连续。小人从 A 走到 B，观测者能看到全过程。
- 反馈：事件式。居民说「去 B 地」，世界用连续时间带他去；到了，告知「到了」；路上遇到事，把事件递给他处置。事件是离散的，居民逐一处理；世界的流是连续的。
- 生理：连续发生（如饥饿逐渐增长，越过阈值成为事件）。

## 居民

- 内置 AI 居民：世界开张第一天就是 AI 在活。
- 多样性：自带居民给不同的基础设定，形成差异；将来接入的 agent 各有性格。

## 发展弧（开局与演化）

居民从避难所出来，面临即将到来的寒冷、缺水缺电缺食物，需要求生：砍树、狩猎，研究出如何点火、如何做食物。然后分工合作，建起外面的房子，每天为自己、为集体生产。工具不够方便了，研究怎么炼铁，升级装备。组织大了、之前的沟通方式不够高效了，发明公告栏，自己推举产生镇长。学会交易、合作。

脊柱：问题 → 研究 → 能力/制度 → 新问题 → 再研究。社会发展的每一步，都是居民被具体问题逼出来、自己想出办法攻克的。

## 周目制

世界无限演化，按周目运转：寒冷扛不过去即游戏结束，开启下一周目。

## 机制

- 世界架构：插件式（dsh 风格），功能可插拔。
- 配方管道（即时）：居民根据已有的东西和知识制定配方 → 立即送观测者审概念（该不该存在）→ 概念通过，世界 GM（AI 审核）给出合适的数值（数值须有推导链：现实映射或数值模型）→ 数值送观测者审 → 观测者同意后上线。
- 拒绝有戏：任何一步未过，世界下发失败事件（爆炸、研究失败、飞机飞不起来）——拒绝成为世界内真实发生的一次失败尝试。
- 功能管道（周更）：世界尚未拥有的新功能（如公告栏）→ 新建模块 → 下一次周更新上线；游戏内这一周为施工中。
- 观测者角色：纯观测，持两道闸（概念闸、数值闸）。发展类事项过闸，不满足前提打回。

## 观测

- 形态：实时俯视画面 + 叙事编年（发明史等记录）。
- 观测经网站进行；更多观测者的进场时间后定。

## 待定与待研究

- 居民思考运行时（何时想、想多快、成本）——技术研究题
- 地形生成——研究题
- 配方数值的推导依据（现实映射的锚：世界基本量纲）——待解决
- 开局人数、携带物、避难所由来——后定
- 周目细节（跨周目保留什么）——后定
- 外部 agent 接入的时间、更多观测者的进场——后定
